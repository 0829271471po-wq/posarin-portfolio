# Posarin Sukdee Portfolio

Website portfolio ของ โปสรินท์ สุขดี (โปโล) ม.6 โรงเรียนอยุธยาวิทยาลัย สำหรับยื่น TCAS70 วิศวกรรมคอมพิวเตอร์ มหาวิทยาลัยเกษตรศาสตร์

**ดูเว็บ:** https://posarin-portfolio.netlify.app

## ผลงานในเว็บ (แต่ละอันมี repo ของตัวเอง)

| ผลงาน | repo |
|---|---|
| GuardianEye กล้อง AI จับคนล้ม (ESP32-CAM + Python) | [guardianeye](https://github.com/0829271471po-wq/guardianeye) |
| AI ส่วนตัวที่จำเรื่องของเราได้ (Telegram + LLM) | [personal-ai](https://github.com/0829271471po-wq/personal-ai) |
| Polo Optimizer โปรแกรมดูแลคอม Windows | [polo-optimizer](https://github.com/0829271471po-wq/polo-optimizer) |

## ตัวเว็บ

- HTML, CSS และ JavaScript ล้วน ไม่ใช้ framework
- บัตรนักเรียน 3D ใช้ three.js และ rope physics ที่เขียนเอง (`card3d.js`)
- PosarinBot ตอบคำถามจาก keyword ใน `script.js` ไม่ได้ใช้ AI จริง
- ขึ้นเว็บด้วย Netlify ผ่านสคริปต์ `deploy.ps1`
