          01

          

             AI CAMERA
            
GuardianEye กล้องจับคนล้ม และจำหน้าคนในบ้านได้

            
ที่บ้านผมมียายอยู่ด้วย ผมเลยคิดอยู่บ่อยๆ ว่าถ้าวันไหนยายล้มตอนที่ไม่มีใครอยู่ใกล้ๆ จะทำยังไง เลยลองเอากล้อง ESP32-CAM (ตัวละประมาณ 300 บาท) มาตั้งไว้ ให้มันส่งภาพเข้าคอมพิวเตอร์ แล้วให้คอมพิวเตอร์ดูว่ามีคนล้มไหม และจำหน้าว่าเป็นใคร ถ้าล้มแล้วไม่ลุกขึ้นมา มันจะส่งรูปเข้า Telegram พร้อมบอกชื่อคนที่ล้ม และถ้ามีคนแปลกหน้าเข้ามาในบ้านก็เตือนด้วย

            

               กล้อง ESP32
               ดูท่าทาง
               ดูหน้าว่าใคร
               ส่งเข้า Telegram
            

            

              ของจริงบนโต๊ะบอร์ด ESP32-CAM ต่อไฟ แล้วส่งภาพเข้าคอมพิวเตอร์ที่ run GuardianEye
              จำหน้าได้รู้ว่าเป็นแม่ (mom) พร้อมวาดโครงร่างกายตามท่าทาง
              สงสัยว่าล้มทดสอบนอนที่พื้น ระบบนับเวลาก่อน ถ้าไม่ลุกเกิน 10 วินาทีถึงจะเตือน
              แจ้งเข้ามือถือส่งรูปเข้า Telegram ถ้ารู้จักหน้าจะบอกชื่อ เช่น "คุณแม่ ล้มที่ห้องนั่งเล่น"
            

            
    
              
  • ตอนแรกแค่นั่งเก้าอี้หรือก้มเก็บของมันก็เตือนแล้ว เลยต้องเพิ่มเงื่อนไข ให้ดูว่าตัวเอียงแค่ไหน สะโพกตกเร็วไหม แล้วต้องนอนอยู่เกิน 10 วินาที ถึงจะนับว่าล้ม
    • 
              
  • ตัว ESP32-CAM มี RAM น้อยจน run AI เองไม่ได้ เลยให้มันส่งภาพมาอย่างเดียว ให้คอมพิวเตอร์คิดแทน
    • 
              
  • จำหน้าคนในบ้านได้ (ใช้ OpenCV YuNet + SFace) ถ้าในภาพมีหลายคน มันจะจำหน้าไว้ตั้งแต่ตอนเดินผ่าน ล้มแบบหันหลังให้กล้องก็ยังรู้ว่าเป็นใคร ส่วนคนที่ไม่รู้จักจะเตือนว่าเป็นคนแปลกหน้า
    • 
              
  • ถ้า Wi-Fi สะดุดหรือกล้อง reboot มันจะต่อกล้องใหม่เองทุก 3 วินาที ไม่ต้องปิดเปิดโปรแกรมใหม่
    • 
            

            
 ทำให้มันจับได้ว่ามีคนล้มไม่ยากเท่าไหร่ ที่ยากคือทำยังไงไม่ให้มันเตือนมั่ว เพราะถ้าเตือนผิดบ่อยๆ คนในบ้านก็จะไม่สนใจมันแล้ว

          02

          

             PERSONAL AI
            
AI ส่วนตัวที่จำเรื่องของเราได้

            
Chatbot ทั่วไปพอเปิด chat ใหม่ก็ลืมหมดว่าเราเคยคุยอะไรไว้ เลยลองเขียน AI ไว้คุยเองใน Telegram ให้มันเก็บความจำเป็น file ไว้ในคอมพิวเตอร์ บอกอะไรไปแล้วมันจำได้ จดโน้ตให้ได้ ส่งรูปให้มันดูก็ได้

            

               พิมพ์ใน Telegram
               ส่งไปให้ LLM
               จำ / จดโน้ต
               ตอบกลับ
            

            

              จำเรื่องที่เคยคุยได้ถามชื่อ ร้านประจำ หรือ ม. ที่อยากเข้า มันตอบได้จากความจำ
              ส่งรูปให้ดูได้ส่งรูปบอร์ด ESP32-CAM ไป มันบอกได้ว่าคืออะไร ใช้ทำอะไร
              ความจำเก็บเป็น fileAI บันทึกลง memory.json เอง แต่ละเรื่องมีหมวดและเวลาที่จำ
            

            
    
              
  • ให้ AI เรียก function เองได้ (tool calling) อย่างพิมพ์ว่า "จำไว้นะ" มันก็จะไปบันทึกเอง ถ้าข้อมูลเก่าผิดก็ลบแล้วจำใหม่
    • 
              
  • ตอนทำระบบค้นหา ภาษาไทยมันไม่เว้นวรรค ตัดคำยาก เลยใช้วิธีเทียบทีละ 3 ตัวอักษรแทน
    • 
              
  • คุยครบ 8 ข้อความ มันจะย้อนอ่าน chat แล้วสรุปว่าผมเป็นคนแบบไหน เอาไว้ปรับวิธีตอบ
    • 
              
  • รอคำตอบนานๆ แล้วโดน Cloudflare ตัด เลยเปลี่ยนเป็นค่อยๆ รับคำตอบมาทีละท่อน (stream)
    • 
            

            
 ทำเสร็จแล้วรู้เลยว่าตัว model ไม่ใช่ส่วนที่ยาก ส่วนที่ต้องคิดเยอะคือจะเก็บอะไรไว้ แล้วจะส่งอะไรให้มันดูบ้าง

          03

          

             WINDOWS APP
            
Polo Optimizer โปรแกรมดูแลคอมพิวเตอร์แบบเปิดทีเดียวจบ

            
โปรแกรมดูแลคอมพิวเตอร์ Windows ที่รวมทุกอย่างไว้ในที่เดียว ทั้งลง app หา driver ล้าง file ขยะ และปรับเครื่องเล่นเกม คนที่ใช้คอมพิวเตอร์ไม่เก่งก็กดใช้เองได้ และแจกเป็น Setup.exe ให้คนอื่นลงได้

            

               ตรวจเครื่องจริง
               AI สรุปอาการ
               ผู้ใช้กด "ทำเลย" เอง
            

            

              หน้าเริ่มต้นแนะนำโปรแกรมและวิธีใช้ 4 ขั้นตอน
              หน้าแรกให้คะแนนสุขภาพเครื่อง บอกว่าควรแก้อะไร กดแก้ได้ทันที
              ผู้ช่วย AIเล่าอาการเป็นภาษาพูด AI ตรวจเครื่องจริงแล้วบอกวิธีแก้
              ติดตั้ง appเลือกหลาย app แล้วลงทีเดียวผ่าน winget
            

            

              ในโปรแกรมมีอะไรบ้าง
              
    
                
  • เริ่มต้นแนะนำโปรแกรมและวิธีใช้
    • 
                
  • หน้าแรกดูสเปกและคะแนนสุขภาพเครื่อง ดูแลเครื่องได้ใน click เดียว
    • 
                
  • ผู้ช่วย AIเล่าอาการ แล้ว AI ตรวจเครื่องและบอกวิธีแก้
    • 
                
  • ติดตั้งแอปลงหลาย app พร้อมกันใน click เดียว
    • 
                
  • ไดรเวอร์หา driver ที่ขาด แล้วพาไปที่ website ผู้ผลิตให้ตรงรุ่น
    • 
                
  • ล้างเครื่องลบ file ขยะ และคืน RAM
    • 
                
  • ปรับเล่นเกมเปิด Game Mode ปรับ mouse และแผนพลังงาน
    • 
                
  • เปิดพร้อมเครื่องปิดโปรแกรมที่ไม่จำเป็นตอนเปิดคอมพิวเตอร์ ให้เครื่องเปิดเร็วขึ้น
    • 
                
  • แก้ปัญหาแก้ internet หลุด taskbar ค้าง และซ่อม file ระบบ
    • 
              

            

            
    
              
  • อ่าน Hardware ID เพื่อรู้ว่าอุปกรณ์ที่ยังไม่มี driver เป็นของค่ายไหน แล้วพาไปโหลดให้ถูกตัว
    • 
              
  • AI ตรวจเครื่องจริงก่อนตอบ เช่น internet เสีย จะเช็กทีละจุดจนเจอว่าเสียตรงไหน
    • 
              
  • สระภาษาไทยในโปรแกรมหลุด เลยเขียนตัวตัดบรรทัดภาษาไทยเอง
    • 
              
  • ปลอดภัยไว้ก่อน ไม่ปิด Windows Defender ไม่ลบ file ส่วนตัว และ AI สั่งอะไรเองไม่ได้
    •

        04 — WHY KU
        
ผมแก้คอมพิวเตอร์เป็นแล้ว
ต่อไปอยากสร้างมันเป็น

        
ผมไม่ได้เป็นแค่คนที่อยากเรียนวิศวกรรมคอมพิวเตอร์ ผมเป็นคนที่เริ่มทำไปแล้ว

      

      
ตอนทำ project ผมเจอปัญหาที่ยังแก้ไม่ได้หลายอย่าง และพบว่ามีวิชาใน ม.เกษตร ที่สอนเรื่องพวกนี้ตรงๆ

      

        

          
01204332 ระบบปฏิบัติการ01204225 สถาปัตยกรรมและองค์ประกอบคอมพิวเตอร์

          
ทำไมเครื่องเดิมถึงเล่นเกมไม่ลื่นเหมือนเดิม

          
คำถามแรกที่ทำให้ผมเริ่มแกะคอมพิวเตอร์ ตอนนี้รู้แค่ว่าเกี่ยวกับการจัดการทรัพยากรของระบบ แต่ยังไม่เข้าใจว่าข้างในจัดการยังไง

           ต่อยอด Polo Optimizer ให้แก้ที่สาเหตุ ไม่ใช่แค่ทำตามสูตร
        

        

          
01204371 เทคนิคการแปลงในการประมวลผลสัญญาณ01204216 ความน่าจะเป็นและสถิติสำหรับวิศวกรคอมพิวเตอร์

          
ทำให้ระบบจับคนล้มแม่นขึ้น

          
ตอนนี้ GuardianEye เลี่ยงการเตือนผิดด้วยเงื่อนไขที่ปรับเอง อยากเข้าใจการประมวลผลสัญญาณ และวัดความแม่นยำได้อย่างถูกวิธี

           GuardianEye ตรวจจับการล้มได้แม่นขึ้น
        

        

          
01204322 ระบบฝังตัว01204421 เครือข่ายคอมพิวเตอร์

          
ให้ระบบทำงานต่อได้แม้มีปัญหา

          
ESP32-CAM มี RAM น้อยจน run AI เองไม่ได้ และถ้า Wi-Fi หลุดหรือคอมพิวเตอร์ดับ ระบบก็หยุด ซึ่งไม่ควรเกิดกับระบบที่ดูแลคน

           GuardianEye ทำงานบนตัวกล้องได้มากขึ้น และทำงานต่อเนื่อง
        

        

          
01204437 ความปลอดภัยระบบคอมพิวเตอร์

          
กล้องในบ้านต้องปลอดภัย

          
เรียน Cybersecurity ของ Cisco มาแล้ว เลยรู้ว่ากล้อง ESP32-CAM ตอนนี้ยังไม่มีรหัสผ่าน ถ้าเปิดออก internet ใครก็ดูภาพในบ้านได้

           ทำให้ภาพจากกล้องปลอดภัยก่อนใช้จริง
